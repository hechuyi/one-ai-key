Implemented capability:

  boundary between local no-route admission failure and selected-upstream 5xx
  failure;

  with one safe next action;

  cases without storing sample bodies in runtime configuration;
- production smoke is an explicit operator-run contract with redacted JSON
  output and a local mock success test;
- startup, offline diagnostics, registry validation, and runtime reload now use
  a shared control-plane source, overlay, compiler, and runtime assembly
  boundary while request forwarding remains on compiled in-memory state.

Explicit boundaries:

- GitHub release publication is a separate stop node.
- Deployment pin verification is a separate operator-run stop node.
- Production smoke remains operator-run and is not a local CI dependency.
- No live upstream model catalog aggregation, automatic key rotation, background
  key probing, broad protocol adapter, hosted multi-tenancy, billing, or UI was
  added.

Deferred scope:

- fully explicit reload credential-source injection can further reduce
  management validation coupling in a later control-plane cleanup;
- deployment hosts should pin published release assets by URL and hash rather
  than building from source.
